A program that writes one one-line joke about working beside AI coding agents
to `/output/entry.txt`. An AI judge compares the jokes two at a time.

Entry for the [make.fun bounty](https://make.fun/bounty/the-joke-about-the-demo-20261123-0112)
"the-joke-about-the-demo-20261123-0112" ($50, top 20 paid).

## Run

```sh
node main.ts
```

`MAKEFUN_OUTPUT_DIR` sets the output directory (default `/output`).
The program writes `entry.txt` there: one line, 1–280 characters, deterministic.
